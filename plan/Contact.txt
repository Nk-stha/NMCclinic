  SEO Architecture

  Recommended SEO target: local clinic contact/search intent.

  Suggested metadata pattern:

  - Meta title: Contact NMC Clinic Butwal | Address, Phone & Opening Hours
  - Meta description: Include clinic location, phone, opening hours, and appointment/contact intent.
  - Canonical URL: /contact
  - Robots: index, follow
  - H1: keep one clear H1, currently acceptable.
  - Structured data:
      - MedicalClinic
      - PostalAddress
      - GeoCoordinates
      - OpeningHoursSpecification
      - ContactPoint
      - BreadcrumbList

  Important: map coordinates and placeholder phone numbers should not be treated as real business data until verified.

  ———

  Performance

  Recommended:

  - Generate the OpenStreetMap iframe only from saved coordinates.
  - Lazy-load the map iframe.
  - Keep contact page mostly static if contact details do not change often.
  - Cache page content and business settings.
  - Do not cache submitted form requests.
  - Minimize JS needed for the form.

  For a future Next.js setup:

  - SSG/ISR is suitable for page content.
  - Server action/API route is needed for form submission.
  - Revalidate contact page when CMS content changes.

  ———

  Security

  Required before making the form real:

  - Sanitize name, phone, email, subject, and message.
  - Validate phone/email server-side.
  - Add rate limiting.
  - Add spam protection.
  - Store consent timestamp.
  - Do not expose recipient emails directly in frontend data.
  - Validate uploaded SEO/social images if CMS supports media.
  - Add CMS permissions for editing contact settings.
  - Add audit logs for changes to phone, address, email, and hours.

  ———

  Risks

  - Current form does not actually send or store messages.
  - Phone numbers look like placeholders.
  - Map coordinates may not be verified.
  - Consent checkbox references agreement but footer privacy links currently point to #.
  - No SEO metadata exists in the static page.
  - Emergency message exists, but emergency routing is still just a phone link.
